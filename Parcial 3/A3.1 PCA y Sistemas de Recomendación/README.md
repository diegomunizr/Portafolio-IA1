## 📌 Descripción

En esta actividad se trabajó con técnicas de **reducción de dimensionalidad** mediante **PCA (Principal Component Analysis)** y con la implementación de **sistemas de recomendación** utilizados en aplicaciones modernas para sugerir contenido personalizado a los usuarios.

El desarrollo incluyó análisis de datos, procesamiento de información y aplicación de algoritmos de aprendizaje automático utilizando Python y herramientas del ecosistema de ciencia de datos.

---

## 📚 Temas Cubiertos

### 📉 PCA (Principal Component Analysis)
- Introducción a la reducción de dimensionalidad
- Análisis de componentes principales
- Transformación y proyección de datos
- Interpretación de componentes principales
- Optimización y compresión de información

---

### 🎯 Sistemas de Recomendación
- Introducción a los sistemas de recomendación
- Filtrado colaborativo
- Recomendaciones basadas en similitud
- Predicción de preferencias de usuarios
- Aplicación de modelos de recomendación
