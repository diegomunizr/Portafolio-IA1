# Certificado – Curso 3
## Aprendizaje No Supervisado, Recomendadores y Aprendizaje por Refuerzo

Este directorio contiene las evidencias, actividades y materiales correspondientes al curso realizado en Coursera sobre técnicas de aprendizaje no supervisado, sistemas de recomendación y aprendizaje por refuerzo.

Cada semana incluye su propio archivo `README.md` con descripción detallada de los temas vistos, actividades realizadas y evidencias de finalización.
