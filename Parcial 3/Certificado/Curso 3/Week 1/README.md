## 📌 Descripción

Esta semana se enfocó en el estudio del **aprendizaje no supervisado**, especialmente en técnicas de **agrupamiento (clustering)** y **detección de anomalías**. Se exploró el algoritmo **K-means**, métodos para seleccionar conglomerados y sistemas para identificar eventos inusuales dentro de los datos.
